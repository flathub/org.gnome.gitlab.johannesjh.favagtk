# favagtk (Flathub Packaging Repository)

This repository contains the Flatpak packaging for favagtk, a GNOME desktop application for managing your finances using Fava and Beancount.

## What is favagtk?

favagtk lets you do your finances using Fava and Beancount in a convenient GNOME desktop application.

Fava and Beancount are powerful, open-source, plaintext bookkeeping and accounting tools. favagtk wraps them in a user-friendly graphical interface, making it easy to work with your financial data on the desktop without giving up the flexibility and transparency of plain text.

You can find more information in the homepages and repositories of the following projects:

- favagtk <https://gitlab.gnome.org/johannesjh/favagtk>
- fava <https://github.com/beancount/fava>
- beancount <https://github.com/beancount/beancount>

## Installation

favagtk can be installed from [flathub](https://flathub.org/apps/details/org.gnome.gitlab.johannesjh.favagtk).

## What is this repository for?

This repository is for packaging favagtk (as a flatpak app) and for publishing it on flathub. This concerns

- Flatpak manifest
- Runtime and dependency configuration
- Flathub CI (continuous integration) for building and publishing the app
- Packaging-related issues and fixes

## Contributing to this repository

If you’re interested in favagtk's flatpak packaging, help is always welcome 🙂  
Examples of useful contributions here include:

- Keeping the manifest in sync with new upstream releases
- Fixing build or runtime issues specific to Flatpak

Note that other activities such as design, development, maintenance, updates etc... all take place in the upstream development repository. 

## Where does favagtk development take place?

In the upstream development repository on GNOME GitLab:  
https://gitlab.gnome.org/johannesjh/favagtk

The upstream development repository is the right place for:

- Bug reports
- Feature requests
- Merge requests (pull requests)
- General discussion about favagtk’s behavior or design

## Where should I report bugs or request features?

In the upstream development repository.

Please do not open issues or pull requests here in this packaging repository. Issues opened here for non-packaging topics may be closed or redirected. If you’re unsure whether something belongs here or upstream, feel free to ask—or open an issue and we can point you in the right direction.
